# Teaching

`teaching` changes a coding agent's job from finishing code quickly to helping a learner build a reliable mental model. It asks for predictions before running code, introduces one concept at a time, uses errors as evidence, and ends with a teach-back.

Use it for a language, library, codebase, PR, or concept you want to understand. A one-off walkthrough needs no book. In a longer learning project, the skill can guide chapter writing and keep private session notes in the learner's chosen note system.

The main workflow is in [`SKILL.md`](SKILL.md). The `references/` folder holds operating rules, pedagogy background, and templates for chapters, exercises, teacher notes, and optional private session notes.

[`bookgen`](../bookgen/SKILL.md) uses this skill to create a multi-session learning book around a real repository.
