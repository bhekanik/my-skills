# Meta concept namespace (starter)

Pedagogy-level tags that aren't tied to one language. Use the `meta/` prefix so they're distinguishable from language concepts in the chain graph.

- `meta/predict-before-run`
- `meta/surface-your-model`
- `meta/compiler-as-teacher`
- `meta/pain-anchor-framing`
- `meta/gradual-release`
- `meta/teach-back`
- `meta/build-philosophy`         # artifact-per-session (rule 13)
- `meta/evidence-posture`         # consensus/tension/pitfall/gap (rule 20)
- `meta/socratic-pressure`        # pressure modes (rule 21)
- `meta/learner-state`            # carry state every turn (rule 22)
- `meta/prerequisite-descent`     # recursive descent on a stall (rule 23)
- `meta/varied-practice`          # transfer exercises (rule 19)

Ceremony chapters that produce no language concept still teach *something* — tag them `meta/build-philosophy` or the relevant tooling concept rather than leaving `teaches:` empty (an untagged chapter is invisible to the chain).
