# Concept namespaces — starter lists

Canonical concept slugs per language, for the `teaches:` / `requires:` chapter frontmatter (see `../templates/chain/concept-tags-spec.md`). Reusing a slug from here keeps the cross-book concept graph (`chain_index.py` → `concept-dag.json`) coherent across books generated by different agents and learners.

## How to use

- When tagging a chapter, prefer an existing slug from the matching `<lang>.md` over coining a near-duplicate (`rust/drop-trait`, not `rust/drop-traits`).
- These are **starters, not exhaustive.** Add new slugs as the chain grows; keep kebab-case and terse.
- Pedagogy-level tags (not language-specific) live in `meta.md` (`meta/predict-before-run`, `meta/pain-anchor-framing`).
- Use the `/aspect` suffix when one chapter teaches part of a concept and a later chapter teaches the rest: `rust/drop-trait/gloss` then `rust/drop-trait/full`.

## Files

- `rust.md`, `go.md`, `swift.md`, `swiftui.md`, `zig.md`, `ocaml.md`, `elixir.md` — per-language starters
- `meta.md` — pedagogy/cross-language tags

`chain_index.py --also-list-concepts` prints the namespace actually in use across a chain; reconcile it against these starters periodically.
